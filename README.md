# Rusty

A modern Lisp dialect implemented in Rust with TCO, hygienic macros, and more.

## Features
- Tail Call Optimization (TCO)
- Hygienic Macros (`defmacro`)
- `let`, `let*`, `letrec`
- `cond`, `and`, `or`
- Full lexical scoping and closures
- REPL and file loading

## Build & Run
```bash
cargo run
cargo build --release
```
